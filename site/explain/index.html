How a program turns a rule into an evaluation profile — and how an edit travels

Pick a rule from the invented code-review spec. The concept layer program first reads the rule into a small model — the action being judged, the conditions that must all hold, the exceptions that avoid a violation, the facts a verdict turns on — and then writes each part of the profile from that model. Step through it, then add an author's exception and watch it reach every part. Compare the flat program, whose parts are written independently, and the chained one, where each verdict part reads the previous.
